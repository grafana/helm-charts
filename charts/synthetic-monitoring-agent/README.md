# synthetic-monitoring-agent

## 📦 Chart Migration

**This chart is now maintained in the [grafana/synthetic-monitoring-agent](https://github.com/grafana/synthetic-monitoring-agent/tree/main/charts/synthetic-monitoring-agent) repository.**

Version 2.0.0 is a new chart that replaces the 1.x charts previously published from this repository and from [grafana-community/helm-charts](https://github.com/grafana-community/helm-charts). It's published to the `grafana` Helm repository, `https://grafana.github.io/helm-charts`, and as an OCI artifact, `oci://ghcr.io/grafana/helm-charts/synthetic-monitoring-agent`.

Most values are renamed in 2.0.0. To migrate a 1.x release, follow the [upgrade instructions](https://github.com/grafana/synthetic-monitoring-agent/tree/main/charts/synthetic-monitoring-agent#upgrading) in the chart README.

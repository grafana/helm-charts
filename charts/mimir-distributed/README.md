# Notice of relocation

## ⚠️ Deprecation and move to grafana-community

The `mimir-distributed` chart is deprecated. `mimir-distributed` 6.3.0, released from [grafana/mimir](https://github.com/grafana/mimir), will be its last release. The chart is moving to the community-maintained [grafana-community/helm-charts](https://github.com/grafana-community/helm-charts) repository, where new issues and pull requests should be opened. See [grafana/mimir#17112](https://github.com/grafana/mimir/issues/17112) and [grafana-community/helm-charts#828](https://github.com/grafana-community/helm-charts/issues/828) for details.

## Usage

Releases up to and including 6.3.0 are published from [grafana/mimir](https://github.com/grafana/mimir/tree/main/operations/helm/charts/mimir-distributed) to the [https://grafana.github.io/helm-charts](https://grafana.github.io/helm-charts) Helm repository, and remain available there.

## Issue tracking

Open new issues in [grafana-community/helm-charts](https://github.com/grafana-community/helm-charts/issues).

## Contributing

Open new pull requests against the `main` branch of [grafana-community/helm-charts](https://github.com/grafana-community/helm-charts). See its [contributing guide](https://github.com/grafana-community/helm-charts/blob/main/CONTRIBUTING.md).
